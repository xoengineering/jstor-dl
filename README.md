# jstor-dl

Download articles from JSTOR's public-domain Early Journal Content for offline archives.

`jstor-dl` fetches only from the Internet Archive's copy of the Early Journal Content, never from jstor.org. JSTOR's terms forbid any tool from downloading from jstor.org, even a single article.

## Development

```sh
script/setup    # install dependencies
script/test     # run specs and rubocop
script/console  # interactive prompt
```
